SIT218 Task 7.3HD Demo App

Every feature below exists in two versions: a deliberately vulnerable one under /vuln/, and a hardened one under /secure/ or /secure-auth/.

Vulnerable versions (/vuln/**) - no login required

  • Progress notes - Stored XSS
  • Member search - SQL Injection
  • File upload - Unrestricted upload
  • Profile update - CSRF
  • Member directory - Data aggregation / inference

Secure versions (Task 3 fixes, /secure/**) - no login required

  • Progress notes (validated + escaped)
  • Member search (parameterized query)
  • File upload (validated)
  • Profile update (custom CSRF token)
  • Member directory (auth + generalized, login required)
  • Member detail (controller-level exception handler demo)
  • Member detail for a non-existent id (triggers the handler)

Task 4 - Spring Security auth + role-based access + default CSRF
